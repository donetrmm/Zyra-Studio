# Design Context — 1to1 Studio

Sintetizado de `docs/Identidad de Marca.md`, `ZyraStudioV2/OBJETIVO.md` y
`ZyraStudioV2/ARQUITECTURA-Y-CAPACIDADES-V2.md`. Rebrand 2026-06-11: el producto
se llama **1to1 Studio** (antes Zyra Studio) y el acento es azul `#009fff`
(`#0072e6` sobre fondos con texto blanco), logo cubo isométrico azul.

## Design Context

### Users

Marketers, creadores de contenido, agencias pequeñas y freelancers que producen
anuncios para Meta/TikTok/YouTube. El usuario objetivo de V2 **no es diseñador
ni director creativo**: el sistema encapsula ese oficio. Contexto de uso:
sesiones de trabajo largas en desktop (dark mode), produciendo campañas
completas — no clips sueltos. Una sola persona debe rendir como un equipo.

### Brand Personality

Minimalista premium, futurista, profesional, cercana. Tono claro y moderno, en
español. Slogan: "Create Beyond Limits". Sin emojis en UI. La interfaz debe
evocar confianza y competencia ("esto sabe lo que hace"), nunca complejidad de
herramienta pro tipo After Effects.

### Aesthetic Direction

Dark mode por defecto, base zinc-950, acento azul `#009fff` / `#0072e6`
(contraste AA con texto blanco), componentes shadcn. Bordes redondeados,
animaciones suaves y discretas. Anti-referencia: dashboards saturados de
métricas, editores con cientos de controles visibles, estética "AI slop"
(glows neón, gradient text, glassmorphism decorativo).

### Design Principles (V2)

1. **Curva de aprendizaje mínima**: el conocimiento experto vive en el sistema
   (Prompt Director, formatos, plantillas), no en la cabeza del usuario.
2. **Minimizar decisiones, no eliminarlas**: defaults inteligentes en cada paso;
   cada pantalla presenta pocas opciones y una acción primaria obvia.
3. **Progresión por compuertas**: brief → plan → muestra → lote → entrega; el
   usuario aprueba, no configura. Progressive disclosure en todo.
4. **Economía visible**: costo estimado antes de gastar, draft antes de final,
   reporte de valor al cierre. Nunca sorpresas de créditos.
5. **Referencias sobre descripciones**: dirigir mostrando (Brand Kit, Cast,
   plantillas vivas), no escribiendo prompts largos.
