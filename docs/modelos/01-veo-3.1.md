# Google Veo 3.1 — API Documentation

> **Transporte:** Veo es el único modelo Google que sigue en la API nativa
> (`GEMINI_API_KEY`, requests REST tal como documenta este archivo). Gemini
> texto y Nano Banana migraron a Vercel AI Gateway (`AI_GATEWAY_API_KEY`,
> model strings `google/...` vía AI SDK) — Veo se queda fuera porque el
> gateway solo ofrece video bloqueante sin operation name, incompatible con
> el polling re-encolado por QStash. Ver
> `docs/superpowers/specs/2026-07-08-migracion-ai-gateway-design.md`.

**Caso de uso:** Generación de video premium con audio nativo sincronizado, 4K, máxima calidad cinematográfica.

## Acceso

- **Plataforma:** Gemini API (Google AI Studio) o Vertex AI
- **Documentación oficial:** https://ai.google.dev/gemini-api/docs/video
- **API Key:** https://aistudio.google.com/apikey
- **Estado:** Paid Preview

## Modelos disponibles

| Modelo | ID | Uso |
|---|---|---|
| Veo 3.1 | `veo-3.1-generate-preview` | Máxima calidad, 4K |
| Veo 3.1 Fast | `veo-3.1-fast-generate-preview` | Calidad alta, menor latencia |
| Veo 3.1 Lite | `veo-3.1-lite-generate-preview` | Volumen/bajo costo, sin 4K |

## Endpoint REST

```
POST https://generativelanguage.googleapis.com/v1beta/models/veo-3.1-generate-preview:predictLongRunning
```

Header: `x-goog-api-key: $GEMINI_API_KEY`

## Capacidades

- **Duración:** 4, 6 u 8 segundos (obligatorio 8s para 1080p/4K, referencias o extensión)
- **Resoluciones:** 720p, 1080p, 4K
- **Aspect ratio:** `16:9` (landscape, default), `9:16` (portrait)
- **Audio nativo:** siempre activo (diálogo, SFX, ambiente)
- **Frame rate:** 24fps
- **Modalidades de entrada:**
  - Text-to-video
  - Image-to-video (primer frame)
  - First+last frame (interpolación)
  - Reference images (hasta 3, para mantener personajes/objetos)
  - Video extension (extender videos previos hasta 141s totales)

## Parámetros principales

| Parámetro | Valores |
|---|---|
| `prompt` | string (1,024 tokens máx) |
| `image` | Image object (primer frame) |
| `lastFrame` | Image object (último frame) |
| `referenceImages` | Array (hasta 3 imágenes con `reference_type: "asset"`) |
| `video` | Video object previo (para extensión) |
| `aspectRatio` | `"16:9"` \| `"9:16"` |
| `durationSeconds` | `"4"` \| `"6"` \| `"8"` |
| `resolution` | `"720p"` \| `"1080p"` \| `"4k"` |
| `personGeneration` | `"allow_all"` \| `"allow_adult"` |

## Ejemplo Python (text-to-video)

```python
import time
from google import genai
from google.genai import types

client = genai.Client()

operation = client.models.generate_videos(
    model="veo-3.1-generate-preview",
    prompt="A cinematic shot of a majestic lion in the savannah.",
    config=types.GenerateVideosConfig(
        aspect_ratio="16:9",
        resolution="1080p",
    ),
)

while not operation.done:
    time.sleep(10)
    operation = client.operations.get(operation)

video = operation.response.generated_videos[0]
client.files.download(file=video.video)
video.video.save("output.mp4")
```

## Ejemplo Python (image-to-video con referencias)

```python
dress_ref = types.VideoGenerationReferenceImage(
    image=dress_image, reference_type="asset"
)
woman_ref = types.VideoGenerationReferenceImage(
    image=woman_image, reference_type="asset"
)

operation = client.models.generate_videos(
    model="veo-3.1-generate-preview",
    prompt="A woman walks through a turquoise lagoon wearing the dress...",
    config=types.GenerateVideosConfig(
        reference_images=[dress_ref, woman_ref],
    ),
)
```

## Ejemplo cURL

```bash
operation_name=$(curl -s "${BASE_URL}/models/veo-3.1-generate-preview:predictLongRunning" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "instances": [{"prompt": "A cinematic shot..."}],
    "parameters": {"aspectRatio": "16:9", "resolution": "1080p"}
  }' | jq -r .name)
```

## Patrón asíncrono

Veo es long-running. Flujo:
1. POST a `:predictLongRunning` → devuelve `operation.name`
2. Polling GET cada 10s hasta `done: true`
3. Descargar video desde `response.generateVideoResponse.generatedSamples[0].video.uri`

## Audio prompting

- **Diálogo:** entre comillas. Ej: `"This must be the key," he murmured.`
- **SFX:** descripción explícita. Ej: `tires screeching loudly`
- **Ambiente:** descripción de soundscape. Ej: `A faint eerie hum resonates`

## Buenas prácticas de prompt

Estructura recomendada: **Subject + Action + Style + Camera + Composition + Focus + Ambiance**

Ejemplo: `Close-up shot (composition) of melting icicles (subject) on a frozen rock wall (context) with cool blue tones (ambiance), zoomed in (camera motion) maintaining close-up detail of water drips (action).`

## Limitaciones

- Latencia: 11s a 6min (peak)
- Retención de videos generados: 2 días
- Watermark SynthID en todos los outputs
- En EU/UK/CH/MENA: `personGeneration` limitado a `allow_adult`
- 1 video por request (Veo 3.1)
- Extension solo soporta 720p
