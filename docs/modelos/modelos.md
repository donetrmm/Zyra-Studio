\# Stack de Modelos de IA Generativa



\## Video



| Modelo | Caso de uso |

|---|---|

| \*\*Google Veo 3.1\*\* | Default para máxima calidad. Videos con audio nativo sincronizado, 4K, prompt adherence alta. Usar para entregables finales, demos premium, contenido cinematográfico. |

| \*\*Kling 3.0\*\* | Volumen y videos con personajes. Cuando se necesitan múltiples iteraciones a bajo costo, escenas multi-shot con el mismo personaje, lip-sync para avatares. |



\## Imagen



| Modelo | Caso de uso |

|---|---|

| \*\*Nano Banana Pro\*\* | Default. Generación general, edición multi-imagen, consistencia de personajes (hasta 8 referencias), infografías con datos, recreación de escenas con referencias. Cubre el 80% de los casos. |

| \*\*FLUX 2 Pro\*\* | Fotorrealismo crítico. Hero shots, fotografía de producto, retratos hiperrealistas, assets de branding premium donde la fidelidad fotográfica es prioridad. |



\## Audio



| Modelo | Caso de uso |

|---|---|

| \*\*ElevenLabs\*\* | Todo voz. Narración, voiceovers, doblaje, voice cloning, español latino expresivo, audiobooks. Único modelo necesario para el caso de uso. |
